1  Tiga Distribusi yang Harus Dibedakan

Distribusi Isinya Jumlah nilai Contoh
Distribusi populasi Nilai setiap unit populasi N Pengeluaran 20.000 mahasiswa
Distribusi sampel Nilai unit dalam satu sampel n Pengeluaran 40 mahasiswa yang disurvei
Distribusi sampling Nilai statistik (misalnya ) dari ̄𝑥banyak sampel Sebanyak sampel yang (dibayangkan) diambil 𝑥 dari 10.000 sampel berukuran 40

Distribusi sampling adalah konsep teoretis: dalam praktik kita hanya memiliki satu sampel. Namun dengan simulasi kita dapat “melihatnya”.

1.1 Populasi Simulasi

Kita memakai populasi 20.000 mahasiswa dengan variabel waktu layar harian (jam) yang menjulur kanan - bentuk yang sengaja dipilih jauh dari lonceng.

set.seed(909)
N <- 20000
populasi <- round(rgamma(N, shape = 2, rate = 0.4), 2) # jam per hari
mu <- mean(populasi)
sigma <- sqrt(mean((populasi - mu)^2)) # SD populasi (pembagi N)
c(N = N, mu = round(mu, 3), sigma = round(sigma, 3))
        N        mu     sigma 
20000.000     5.010     3.551 
set.seed(1)
satu_sampel <- sample(populasi, 40)
banyak_rata <- replicate(10000, mean(sample(populasi, 40)))
par(mfrow = c(1, 3))
hist(populasi, breaks = 40, col = "#9ecae1", border = "white", main = "Populasi (N= 20.000)",
xlab = "Jam per hari", xlim = c(0, 20))
hist(satu_sampel, breaks = 12, col = "#fdae6b", border = "white", main = "Satu sampel (n = 40)",
xlab = "Jam per hari", xlim = c(0, 20))
hist(banyak_rata, breaks = 40, col = "#a1d99b", border = "white",
main = "Sampling distribution x-bar", xlab = "Rata-rata sampel (n = 40)")
par(mfrow = c(1, 1))

Populasi dan satu sampel sama-sama menjulur kanan, tetapi distribusi rata-rata sampel jauh lebih sempit dan hampir berbentuk lonceng. Inilah inti pertemuan ini.

2.1 Pengaruh Ukuran Sampel

set.seed(2)
n_list <- c(5, 20, 80)
par(mfrow = c(1, 3))
for (nn in n_list) {
rata <- replicate(5000, mean(sample(populasi, nn)))
hist(rata, breaks = 40, col = "#a1d99b", border = "white", xlim = c(1, 10), freq= FALSE,
main = paste0("n = ", nn, " (SE = ", round(sigma / sqrt(nn), 2), ")"),
xlab = "Rata-rata sampel")
curve(dnorm(x, mu, sigma / sqrt(nn)), add = TRUE, col = "firebrick", lwd = 2)
abline(v = mu, lty = 2)
}
par(mfrow = c(1, 1))

Kurva merah adalah distribusi normal dengan mean 𝜇 dan SD 𝜎/√𝑛. Semakin besar 𝑛: (1) distribusi semakin sempit, dan (2) bentuknya semakin mendekati normal meskipun populasinya menjulur kanan.

3 Central Limit Theorem (CLT)

Central Limit Theorem. Jika sampel acak berukuran 𝑛 diambil dari populasi sembarang bentuk dengan mean 𝜇 dan simpangan baku 𝜎 (terhingga), maka untuk 𝑛 yang cukup besar, distribusi sampling ̄𝑥 mendekati normal

\[\bar{x} \approx N\left(\mu, \frac{\sigma}{\sqrt{n}}\right)\]

CLT adalah alasan mengapa distribusi normal muncul di mana-mana dalam statistika inferensial–bukan karena data selalu normal, tetapi karena rata-rata dari data cenderung normal.

3.1 Demonstrasi pada Tiga Bentuk Populasi

set.seed(3)
pop_bentuk <- list(
"Seragam" = runif(20000, 0, 10),
"Menjulur kanan" = rexp(20000, rate = 0.5),
"Bimodal" = c(rnorm(10000, 2, 0.8), rnorm(10000, 8, 0.8))
)
ukuran <- c(2, 5, 30)
par(mfrow = c(4, 3), mar = c(3, 3, 2.5, 1))
for (nama in names(pop_bentuk)) {

main = paste("Populasi:", nama), xlab = "", ylab = "")
}
for (nn in ukuran) {
for (nama in names(pop_bentuk)) {

hist(rata, breaks = 35, col = "#a1d99b", border = "white",
main = paste0(nama, ", n = ", nn), xlab = "", ylab = "")
}
}
par(mfrow = c(1, 1), mar = c(5, 4, 4, 2) + 0.1)

Baris pertama adalah populasi; baris berikutnya adalah distribusi sampling ̄𝑥 untuk 𝑛 = 2, 5, dan 30. Populasi seragam sudah tampak lonceng pada 𝑛 = 5; populasi bimodal masih bergelombang pada 𝑛 = 2 tetapi lonceng pada 𝑛 = 30; populasi menjulur kanan membutuhkan 𝑛 terbesar untuk menghilangkan kemencengannya.

3.3 Menghitung Peluang dengan CLT

Contoh: Jika diambil sampel acak 40 mahasiswa, berapa peluang rata-rata waktu layarnya melebihi 5,5 jam?

\[z = \frac{\bar{x} - \mu}{\sigma / \sqrt{n}} \qquad P(\bar{x} > 5,5) = P(Z > z)\]

se40 <- sigma / sqrt(40)
z_55 <- (5.5 - mu) / se40
c(SE = round(se40, 4), z = round(z_55, 3),
Peluang_CLT = round(1 - pnorm(z_55), 4),
Peluang_simulasi = round(mean(banyak_rata > 5.5), 4))
              SE                z      Peluang_CLT Peluang_simulasi 
          0.5615           0.8730           0.1913           0.1803

Perbandingan: peluang seorang mahasiswa (bukan rata-rata 40 orang) memiliki waktu layar di atas 5,5 jam jauh lebih besar:

mean(populasi > 5.5)
[1] 0.35175

Individu sangat bervariasi, tetapi rata-rata dari banyak individu jauh lebih stabil.

6 Estimasi

6.1 Point Estimate

Point estimate adalah satu angka yang menaksir parameter.

Parameter *Point estimate* Penaksir tak bias?
$\mu$ $\bar{x}$ Ya
$p$ $\hat{p}$ Ya
$\sigma^2$ $s^2$ (pembagi $n - 1$) Ya
$\sigma$ $s$ Sedikit bias (diabaikan dalam praktik)

Kelemahan point estimate: hampir pasti tidak tepat sama dengan parameter, dan tidak memberi tahu seberapa jauh melesetnya.

6.2 Confidence Interval (Selang Kepercayaan)

Selang kepercayaan memberikan rentang nilai yang masuk akal bagi parameter:

\[\text{Point estimate} \pm \underbrace{\text{nilai kritis} \times SE}_{\text{margin of error}}\] ### CI untuk Mean, 𝜎 Diketahui (z)

\[\bar{x} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}\]

Tingkat kepercayaan $\alpha$ $z_{\alpha/2}$
90% 0,10 1,645
95% 0,05 1,960
99% 0,01 2,576 
round(qnorm(c(0.95, 0.975, 0.995)), 3)
[1] 1.645 1.960 2.576

6.2.1 CI untuk Mean, 𝜎 Tidak Diketahui (t)

Dalam praktik 𝜎 hampir tidak pernah diketahui dan diganti 𝑠. Penggantian ini menambah ketidakpastian, sehingga nilai kritis diambil dari distribusi t dengan derajat bebas 𝑑𝑓 = 𝑛 − 1:

\[\bar{x} \pm t_{\alpha/2,\, n-1} \frac{s}{\sqrt{n}}\]

curve(dnorm(x), -4, 4, lwd = 2, ylab = "Kepadatan", xlab = "Nilai",
main = "Distribusi t Berekor Lebih Tebal dari Normal")

curve(dt(x, df = 10), add = TRUE, lwd = 2, lty = 3, col = "darkorange")
legend("topright", bty = "n", lwd = 2, lty = c(1, 2, 3), col = c("black", "firebrick", "darkorange"),

Untuk sampel kecil, nilai kritis t lebih besar daripada 1,96 (selang lebih lebar, “hukuman” karena menaksir 𝜎). Saat 𝑛 membesar, distribusi t mendekati normal. Distribusi t dibahas lebih dalam pada Pertemuan 11.

6.2.2 Contoh Perhitungan

Satu sampel 40 mahasiswa (satu_sampel) dipakai untuk menaksir rata-rata waktu layar seluruh mahasiswa.

  40.000    4.915    3.019    0.477    2.023    0.966    3.950    5.881

Laporan: “Rata-rata waktu layar mahasiswa diperkirakan 4.92 jam per hari, dengan selang kepercayaan 95% antara 3.95 dan 5.88 jam (n = 40).”

6.2.3 CI untuk Proporsi

\[\hat{p} \pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1 - \hat{p})}{n}} \qquad \text{syarat: } n\hat{p} \ge 10 \text{ dan } n(1 - \hat{p}) \ge 10\]

x_ya <- 138; n_resp <- 400 # 138 dari 400 responden memakai QRIS setiap hari

c(p_hat = p_hat, SE = round(se_p, 4), MoE = round(moe_p, 4),
Bawah = round(p_hat - moe_p, 4), Atas = round(p_hat + moe_p, 4))

0.3450 0.0238 0.0466 0.2984 0.3916

“Sekitar 34,5% responden memakai QRIS setiap hari, margin of error ± 4.7 poin persentase (kepercayaan 95%)” – format inilah yang sering dikutip media dari hasil survei.

6.3 Menafsirkan Selang Kepercayaan dengan Benar

Kepercayaan 95% adalah sifat prosedurnya, bukan satu selang tertentu: jika pengambilan sampel dan perhitungan selang diulang berkali-kali, sekitar 95% selang yang dihasilkan akan memuat𝜇.

set.seed(7)
B <- 100
selang <- t(replicate(B, {
s_i <- sample(populasi, 40)
m <- mean(s_i); e <- qt(0.975, 39) * sd(s_i) / sqrt(40)
c(bawah = m - e, atas = m + e)
}))
memuat <- selang[, "bawah"] <= mu & selang[, "atas"] >= mu
plot(NULL, xlim = range(selang), ylim = c(1, B), xlab = "Waktu layar (jam)", ylab= "Sampel ke-",
main = paste0("100 Selang Kepercayaan 95%: ", sum(memuat), " memuat mu"))
segments(selang[, "bawah"], 1:B, selang[, "atas"], 1:B,
col = ifelse(memuat, "grey50", "firebrick"), lwd = ifelse(memuat, 1,2.5))
abline(v = mu, col = "#4C72B0", lwd = 2)

Garis merah adalah selang yang gagal memuat 𝜇. Kita tidak pernah tahu apakah selang kita termasuk yang merah – tetapi kita tahu prosedurnya berhasil sekitar 95% dari waktu.

Tafsiran Benar/Salah
“Kami 95% yakin bahwa selang 4,2–5,7 jam memuat rata-rata populasi.” Benar (bahasa sehari-hari yang diterima)
“95% selang yang dibuat dengan prosedur ini akan memuat 𝜇.” Benar (tafsiran paling tepat)
“Ada peluang 95% bahwa 𝜇 berada di antara 4,2 dan 5,7.” Salah – 𝜇 bukan variabel acak; ia di dalam atau di luar selang
“95% mahasiswa memiliki waktu layar antara 4,2 dan 5,7 jam.” Salah – CI adalah tentang rata-rata, bukan individu
“95% rata-rata sampel lain akan jatuh di selang ini.” Salah

7 Menentukan Ukuran Sampel

Sebelum survei, peneliti biasanya menetapkan margin of error (𝐸) yang diinginkan lalu menghitung𝑛 minimum (selalu dibulatkan ke atas).

Parameter Rumus ukuran sampel Keterangan

10 Kesalahan Umum dalam Sampling Distribution dan Estimasi

  1. Menyamakan distribusi sampel dengan distribusi sampling – yang pertama berisi data individu, yang kedua berisi statistik dari banyak sampel.
  2. Mengira CLT membuat data menjadi normal – CLT berbicara tentang distribusi ratarata, bukan data individu.
  3. Menganggap 𝑛 ≥ 30 selalu cukup – data yang sangat menceng atau beroutlier bisa membutuhkan lebih.
  4. Menyamakan SD dan SE – SD mengukur keragaman individu; SE mengukur ketepatan taksiran.
  5. Memakai z padahal 𝜎 tidak diketahui dan 𝑛 kecil – gunakan distribusi t.
  6. Menafsirkan CI sebagai peluang parameter berada di dalam selang tertentu, atau sebagai rentang nilai individu.
  7. Membulatkan ukuran sampel ke bawah – selalu bulatkan ke atas.
  8. Mengira ukuran populasi menentukan ukuran sampel – untuk populasi besar, yang menentukan adalah margin of error, tingkat kepercayaan, dan variabilitas.
  9. Mengira sampel besar menghilangkan bias – ukuran sampel hanya mengecilkan galat acak.
  10. Memakai pendekatan normal untuk proporsi saat 𝑛 ̂𝑝 atau 𝑛(1 − ̂𝑝) kurang dari 10.
  11. Melaporkan point estimate tanpa selang atau 𝑛 – pembaca tidak dapat menilai ketepatannya.

13 Rangkuman dan Kesimpulan

  1. Distribusi sampling menggambarkan bagaimana sebuah statistik bervariasi dari sampel ke sampel; ia adalah fondasi seluruh statistika inferensial.
  2. ̄𝑥 dan ̂𝑝 adalah penaksir tak bias dengan SE masing-masing 𝜎/√𝑛 dan √𝑝(1 − 𝑝)/𝑛.
  3. CLT menjamin distribusi ̄𝑥 mendekati normal untuk 𝑛 cukup besar, apa pun bentuk populasinya; makin menceng populasi, makin besar𝑛 yang dibutuhkan.
  4. SE bukan SD: SE mengecil sebanding 1/√𝑛 – presisi dua kali lipat membutuhkan sampel empat kali lipat.
  5. Selang kepercayaan = point estimate ± nilai kritis × SE. Gunakan z bila 𝜎 diketahui, t bila 𝜎 ditaksir. Kepercayaan 95% adalah sifat prosedur, bukan peluang untuk satu selang.
  6. Ukuran sampel dapat direncanakan dari margin of error yang diinginkan – tetapi tidak dapat menyembuhkan bias sampling.

Jembatan ke sesi berikutnya: Tugas 2 latihan tadi bertanya, “jika mesin bekerja benar, seberapa jarang hasil seperti ini?” Pertanyaan itulah inti uji hipotesis di Pertemuan 10: 𝐻0 , 𝐻1 , tingkat signifikansi, p-value, dan kesalahan Tipe I dan II.
